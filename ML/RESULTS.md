# Results — learned policies for the discrete-event simulator

Every row is an **independent model**: fitted on seeds 1–19 (639 routes), early-stopped on seeds 20–21, and reported on the **whole test batch** (seeds 22–25, 125 routes). Nothing is selected on the test set — the table reports all of them, so the rows are directly comparable to each other and to the baselines stored in `solutions/basecase`.

Generated by `python ML/code/report.py` from `ML/results/all_test.json`.

## Feasibility

A violation ends the run at that stop, so an infeasible run has no duration. Infeasible runs are counted, never averaged, and every percentage above is paired on routes both policies completed — so a policy is **not** better because it posts a good median over the routes it happened to finish. Read the gap column and the infeasible column together.
